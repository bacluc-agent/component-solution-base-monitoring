= Parameters

The parent key for all of the following parameters is `solution_base_monitoring`.

== `namespace`

[horizontal]
type:: string
default:: `syn-solution-base-monitoring`

The namespace in which to deploy this component.


== Example

[source,yaml]
----
namespace: example-namespace
----

== Alert thresholds

Alert thresholds and evaluation windows can be overridden per instance below the `thresholds` map. Values are inserted only into PromQL expressions; annotation text remains unchanged.

[cols="1,1,3"]
|===
| Parameter | Default | Description
| `container_memory_usage_high` | `0.9` | Memory limit usage ratio
| `container_memory_usage_high_for` | `30m` | Required duration for high memory usage
| `container_cpu_usage_high` | `0.9` | CPU limit usage ratio
| `container_cpu_usage_high_for` | `30m` | Required duration for high CPU usage
| `container_memory_requests_too_high` | `0.2` | Memory request usage ratio
| `container_memory_requests_too_high_for` | `36h` | Required duration for high memory request
| `container_cpu_requests_too_high` | `0.2` | CPU request usage ratio
| `container_cpu_requests_too_high_for` | `36h` | Required duration for high CPU request
| `container_readiness_flap_changes` | `4` | Readiness changes in the window
| `container_readiness_flap_window` | `15m` | Readiness flap measurement window
| `container_readiness_flap_for` | `15m` | Required duration for a readiness flap
| `k8up_job_window` | `36h` | Backup success measurement window
| `k8up_job_for` | `1h` | Required duration without a successful backup
| `k8up_prune_job_window` | `264h` | Prune job success measurement window
| `k8up_prune_job_for` | `1h` | Required duration without a successful prune job
| `kube_namespace_not_active_for` | `5m` | Required duration for an inactive namespace
|===

=== Instance override example

[source,yaml]
----
parameters:
  solution_base_monitoring:
    thresholds:
      container_memory_usage_high: 0.8
      container_memory_usage_high_for: 15m
----
