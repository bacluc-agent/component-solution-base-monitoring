= Parameters

The parent key for all of the following parameters is `solution_base_monitoring`.

== `namespace`

[horizontal]
type:: string
default:: `syn-solution-base-monitoring`

The namespace in which to deploy this component.


== Example

[source,yaml]
----
namespace: example-namespace
----

== Alert thresholds

Rule-specific thresholds are declared inline in the rule block, with defaults in `class/defaults.yml`. They can be overridden per instance under `prometheusRules...rules.<RuleName>`. Shared thresholds (used by more than one rule) live under the `thresholds` map. Values are inserted only into `expr` and `for`; annotation text remains unchanged.

=== Shared thresholds

[cols="1,1,3"]
|===
| Parameter | Default | Description
| `rate_window` | `5m` | Rate measurement window
|===

=== Override example

[source,yaml]
----
parameters:
  solution_base_monitoring:
    prometheusRules:
      solution-base-rules:
        spec:
          groups:
            resource-rules:
              rules:
                KubeContainerMemoryUsageHigh:
                  container_memory_usage_high: '0.8'
                  container_memory_usage_high_for: 15m
----

=== Per-namespace configuration

Thresholds are resolved per component instance, so each namespace/tenant class gets its own values. Create one class per monitored namespace and override the thresholds inline:

[source,yaml]
----
# class/my-namespace.yml
parameters:
  solution_base_monitoring:
    namespace: my-namespace
    monitor_namespaces:
      label_value: my-namespace
    prometheusRules:
      solution-base-rules:
        spec:
          groups:
            resource-rules:
              rules:
                KubeContainerMemoryUsageHigh:
                  container_memory_usage_high: '0.7'
                  container_memory_usage_high_for: 10m
----

Float values must stay quoted (`'0.8'`): jsonnet's `%` operator renders unquoted floats as `0.80000000000000004`.
